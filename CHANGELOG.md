# Changelog

OpeningLab follows semantic versioning. User-visible and release-process changes are recorded here.

## [1.0.0] - 2026-08-12

### Added

- Mastered and not-mastered learning filters backed by the canonical progress state.
- Content-derived service-worker cache identities and a deliberate update prompt.
- Curriculum validation, integrity baselines, unit tests, browser tests, accessibility scans, and performance budgets.
- Versioned, recoverable local-data migrations and safer import/export reporting.

### Changed

- Improved mobile lesson playback controls for repeated one-handed use.
- Guided Practice now keeps positive feedback visible alongside the next instruction.
- First-load theme follows the operating-system preference until the user makes an explicit choice.
- Standardized contextual actions, feedback, spacing, focus handling, and touch targets.

### Security

- Documented the local-only data and threat model in `SECURITY.md`.
